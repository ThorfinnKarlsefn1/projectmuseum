Веб - гид для школьного музея с использованием Qr - кодов и звукового сопровождения.


Принцип работы:
1) Скан куара на экспонате.
2) Открывается страница с описанием + голосовым сопровождением.
3) Можно использовать звуковой плеер / прочесть письменное описание, выйти на главную мейн страницу с остальными экспонатами.


Tech Stack:
Python + Flask - генерация сайта;
JS - кастом аудиоплеер + варианты темной / светлой темы;
HTML CSS - адаптивная верстка под телефон, ПК;
GitHub Pages - релиз, хост.


Работа с проектом: 
терминал
pip install -r requirements.txt
python generate_qr.py
python freeze.py

 Структура проекта

- `templates/` — HTML-шаблоны в базе
- `static/` — стили, скрипты, медиафайлы в базе
- `build/` — готовый сайт для публикации после фриза
- `data.json` — данные об экспонатах
- `generate_qr.py` — скрипт генерации QR-кодов
- `freeze.py` — скрипт сборки сайта
- `app.py` — Flask-приложение
